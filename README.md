![winston](https://avatars.githubusercontent.com/u/9682013?s=200\&v=4) ![loki](https://cdn-icons-png.flaticon.com/512/14/14620.png) ![loki](https://upload.wikimedia.org/wikipedia/commons/0/07/Grafana_loki_logo.png)

## Description

Here is an Example of a project where logging is implemented using Winston, and the log data is sent to Grafana Loki for monitoring.

## Require Packgae

```bash
npm winston
npm winston-loki
```

## Installation

To install the dependencies, run the following command:

```bash
npm install
```

```bash
docker-compose up
```

## Running the app

```bash
$ npm run dev
```
